# Приложение джанго для создания групп и постов

## Описание проекта 

Данный проект представляет собой лабораторную работу, в рамках которой мы изучаем основы работы с виртуальными средами, управления зависимостями и оформления документации в формате Markdown. Проект включает практическую реализацию технологий, используемых в веб-разработке с помощью Django, с акцентом на создание четкой структуры проекта, эффективное управление зависимостями и написание понятной документации для пользователей. В результате выполнения лабораторной работы студенты получат навыки работы с инструментами версионирования, развертыванием проектов и подготовкой их к дальнейшему развитию.

## Как установить 
![nav]

### 1. Клонируйте репозиторий
`git clone https://github.com/31ISR/up09-lab5-volodev5.git`

### 2. Перейдите в каталог проекта
`cd`

### 3. Создайте виртуальную среду
```bash python -m venv venv```
### 4. Активируйте виртуальную среду

 - Для Windows: ```bash venv\Scripts\activate ``` - Для Linux: ```bash source venv/bin/activate ``` 

### 5. Установите зависимости

```bash pip install -r requirements.txt ``` 

### 6. Запустите миграции

```bash python manage.py migrate ```

### 7. Запустите сервер

```bash python manage.py runserver ```

### 8. Откройте браузер и перейдите по адресу

``` http://127.0.0.1:8000/ ```
